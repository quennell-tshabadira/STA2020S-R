# STA2020S-R

In lab practicals completed during STA2020S: Applied Statistics, at the University of Cape Town.

Topics Covered:

- Simple + Multiple Linear Regression
- Logistic Regression
- Model Building
- One-way ANOVA
- Two-way ANOVA (without + with Interaction)
- Non-parametric tests
- Time Series (Components, Smoothing, Decomposition, Forecasting, Transformations and ARIMA modelling)

Language: R
